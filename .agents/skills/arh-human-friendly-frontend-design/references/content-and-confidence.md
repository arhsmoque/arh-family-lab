# Content, Confidence, and Recovery

Use this guidance when reading comfort, second-language use, digital confidence, distraction, stress, consequential forms, or assisted channels matter.

## Content

- Put the purpose and next useful action first.
- Prefer common concrete words, active voice, simple tense, and literal language.
- Keep sentences and paragraphs short without making the tone abrupt or childish.
- Use descriptive headings, link text, buttons, and field labels. Avoid `click here`, unexplained icons, and placeholder-only labels.
- Separate instructions. Put requirements before the field or action they constrain.
- Explain acronyms, uncommon terms, implied consequences, dates, units, and numerical concepts.
- Pair helpful images with equivalent text; do not make decoration compete with comprehension.
- Test real long names, translated strings, dates, prices, and error messages.

## Interaction confidence

- Keep navigation and help in familiar, stable locations.
- Make current location, progress, saved state, and system status visible.
- Prefer native semantic controls and progressive enhancement for essential journeys.
- Avoid precision gestures, drag-only actions, memory tests, surprise timeouts, and authentication that blocks paste or password managers.
- Let users review consequential information, undo where practical, and return without losing useful work.
- Avoid unnecessary repeated entry; preserve known information safely.

## Errors

An error must answer:

```text
What happened?
Where is the problem?
What remains saved?
What can I do next?
Where can I get help or use another channel?
```

Use plain, positive, specific language. Do not blame the user or identify an error only by color.

## Assisted and offline routes

Accessibility does not by itself solve lack of access, skill, confidence, trust, or motivation. When the situation scan finds those barriers, preserve a visible phone, in-person, helper, printable, save-and-resume, or other appropriate route. State availability and limitations truthfully.
